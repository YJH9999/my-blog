### 起因：笔记散了一桌面

期末复习 C 语言的时候，我发现自己的资料散落在四个地方：一份学习指南、两份各记一半的笔记、一份"全知"笔记，再加上教材课后题、老师划的重点、历年试卷……每次复习都要在十几个窗口之间反复横跳，找一个小知识点能翻五分钟。

于是我干了一件一劳永逸的事：**把这些东西全部整合成一个网站**。

👉 **[C 语言知识点大全 · C_learn](https://yjh9999.github.io/C_learn/)**

![C_learn 网站首页](/img/v_home.png)

### 里面装了什么

把四份笔记合并、去重、重新编排之后，大概长这样：

- **61 个章节**，按"学习路线篇 → 基础 → 程序控制 → 数据与函数 → 进阶专题 → 附录速查"组织，零基础也能顺着读
- **423 个代码示例**，117 张速查表——所有结论都用 GCC 实机编译验证过，不是纸上谈兵
- **52 处易错点 / 重难点标记**，比如"if 后面多写分号""case 穿透"这类考试收割机考点，都有编号、有解释、有反例
- **172 道实战练习**，分布在各章节末尾

### 几个我自己很喜欢的功能

**🎯 冲刺模式**：考前最后一晚，点一下"只看易错点 / 高频考点"，普通正文自动隐藏，整个网站瞬间变成一份考前清单。

**📝 在线模拟考**：理论题随机组卷、在线判分；编程题直接在网页里写代码运行，不用本地配环境。

**🔍 全文搜索**：`Ctrl + K` 直接搜知识点，找 `%f 和 %lf 的区别` 之类的比翻书快得多。

**📱 手机端也做了适配**，通勤路上刷两章完全没问题。

![手机端效果](/img/v_mobile.png)

### 技术上怎么做的

整个站是一个**纯静态单页**，托管在 GitHub Pages 上，不用服务器、不花钱，加载也快。内容部分是我先整理 Markdown，再用脚本统一渲染排版；界面走的是 macOS 风格，做了深浅色、目录折叠、收藏这些细节。

搭建过程里 AI 帮了大忙——合并四份笔记、生成渲染脚本、调试样式，都省了大量的重复劳动。我的角色更像是"主编"：决定留什么、删什么、按什么顺序排。
